Live 3D energy price intelligence

Read the scene

  • Height is price. Lanes are zones, coloured by country.
  • Baseline Window starts at the session low so small moves stay visible.
  • Baseline Zero keeps a truthful zero axis, including negative prices.
  • Indexed rebases each zone to 100 at the first reading, so shapes compare.
  • Zone focus starts on the 12 busiest zones, with one pick per feed. Choose All zones to plot every zone.

Interact

  • Drag to orbit, scroll to zoom, right-drag to pan.
  • Click a column to pin its reading.
  • Drag across the timeline to brush a time window. Double-click to clear.
  • Pick a date range to load only those UTC days from the snapshot shards.
  • Replay animates the session point by point.

Shortcuts

  • Space Replay / pause
  • 1 2 3 Cameras
  • F Focus selected column
  • R Refresh snapshot
  • L Toggle auto refresh
  • Esc Clear selection
  • ? This panel

Data path

GitHub Action → Kafka producer → Databricks stream → Delta table → SQL Statement API → static JSON on Pages. Your Databricks token never reaches the browser.

A five-minute lane publishes the newest readings; the optional relay adds WebSocket presence and a 20-second Databricks cache.
