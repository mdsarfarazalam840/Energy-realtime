About this page

The hero frame, the orbit rail, the star field and the planet are all WebGL. The panel is an accessible HTML mirror of the selected picture.

Live data comes from api.nasa.gov/planetary/apod. The public DEMO_KEY works without signing up; append ?api_key=YOUR_KEY for a higher limit.

If NASA is unreachable, the page falls back to the last cached snapshot (data/apod.json), then to a labelled demo gallery.
