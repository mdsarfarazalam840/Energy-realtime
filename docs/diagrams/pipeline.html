VoltScope · Data pipeline

Market signal to public dashboard

Two European price feeds become one browser-safe artifact. Credentials stay in CI and Databricks; the public page reads only static JSON.

Ingest contract

  • timestamp · zone · price · source
  • GitHub Actions polls every 30 minutes
  • One Kafka topic carries both feeds

Durable state

  • Delta keeps append-only history
  • Checkpoint lives in a Unity Catalog volume
  • availableNow drains then stops

Public serving

  • SQL token stays in Actions
  • Atomic snapshot commit
  • Browser polls every 60 s
