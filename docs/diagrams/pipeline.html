VoltScope · Data pipeline

Market signal to public dashboard

AEMO five-minute dispatch, ENTSO-E day-ahead, and Elecz DE spot become one browser-safe artifact. Credentials stay in GitHub Actions and Databricks; the public page reads only static JSON, and a five-minute lane keeps the newest readings fresh.

Ingest contract

  • timestamp · zone · price · source
  • GitHub Actions runs the full producer every 30 minutes
  • One Kafka topic carries all three feeds

Durable state

  • Delta keeps append-only history
  • Checkpoint lives in a Unity Catalog volume
  • availableNow drains then stops

Public serving

  • Schema v2 day shards load only the selected dates
  • SQL token stays in Actions
  • Browser polls the manifest every 60 s
