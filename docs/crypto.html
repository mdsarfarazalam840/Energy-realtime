    Read the scene

    • Height is the selected metric. Market cap and volume use a square-root scale; price uses a log scale.
    • Colour follows 24h change by default: green gains, red losses, gold trending.
    • Labels show the ticker and 24h change. The gold ring marks a trending coin.

    Interact

    • Drag to orbit, scroll to zoom, right-drag to pan.
    • Click a column, table row, or trending coin to focus it.
    • Use the metric switch to re-scale every column.
    • Search and the All / Gainers / Losers / Trending filters narrow the market board.

    Data path

    CoinGecko public API → producer_crypto.py → Kafka → Databricks stream → Delta table → SQL Statement API → static JSON on Pages.

    The keyless CoinGecko endpoints supply top coins by market cap and the trending list. The page falls back to a clearly labelled demo snapshot when no export exists.
